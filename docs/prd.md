# 프로젝트 기획서 (PRD) - 마이링크 (My Link)

## 1. 프로젝트 개요

### 프로젝트명
마이링크 (My Link)

### 프로젝트 목적
"마이링크"는 인플루언서, 크리에이터, 프리랜서 등 자신을 알리고자 하는 모든 사용자가 흩어져 있는 자신의 여러 온라인 링크(SNS, 포트폴리오, 연락처 등)를 하나의 페이지로 깔끔하게 모아서 공유할 수 있도록 돕는 멀티링크 서비스입니다.

### 대상 사용자 (Target Audience)
- **콘텐츠 크리에이터 및 인플루언서**: 인스타그램, 틱톡, 유튜브 등 다양한 채널을 운영하며 통합 링크가 필요한 사용자.
- **프리랜서 및 개인 전문가**: 자신의 포트폴리오, 이력서, 이메일 등을 한곳에 모아 명함처럼 활용하고 싶은 사용자.
- **소상공인 및 온라인 셀러**: 스마트스토어, 예약 링크, 문의 채널 등을 한 번에 고객에게 안내해야 하는 사업자.

## 2. 핵심 기능 목록

### 필수 기능 (Must-have) - MVP 범위
1. **사용자 인증 (Authentication)**
2. **프로필 관리 (Profile Management)**
3. **링크 관리 (Link Management)**
4. **마이링크 페이지 뷰어 (Public Page Viewer)**

---

## 3. 각 기능의 상세 설명

### 3.1 사용자 인증 (Authentication)
- **회원가입 및 로그인**: 이메일 및 비밀번호를 통한 기본 회원가입을 지원합니다.
- **소셜 로그인 (OAuth)**: 사용자의 빠른 유입을 위해 구글(Google), 카카오(Kakao), 깃허브(GitHub) 로그인을 지원합니다.
- **아이디/비밀번호 찾기**: 이메일 인증 기반의 계정 복구 기능을 제공합니다.

### 3.2 프로필 관리 (Profile Management)
- **URL 슬러그(Slug) 자동 설정**: 접속 URL은 별도의 기호(@ 등) 없이 사용자의 `displayName`을 기반으로 설정됩니다 (`mylink.com/displayName`). 이 `displayName`의 초기값은 가입 시 사용하는 구글 지메일(Gmail) 아이디의 앞부분(@ 이전)을 추출하여 자동으로 지정됩니다.
- **인라인 편집 (Inline Editing)**: 화면에 표시되는 실제 사용자의 이름(`username`)과 프로필(자기소개) 텍스트는 별도의 폼(페이지)으로 이동할 필요 없이, 화면에서 직접 클릭하여 즉시 수정하는 인라인 편집 방식을 사용합니다.
- **프로필 이미지 업로드 기능 제외**: 텍스트 기반의 깔끔한 구성을 위해 별도의 프로필 이미지 업로드 기능은 제공하지 않습니다.
- **프로필 숨김 처리**: 원할 경우 자신의 페이지를 일시적으로 비공개(Private) 상태로 전환할 수 있습니다.

### 3.3 링크 관리 (Link Management)
- **링크 추가/수정/삭제**: 제목과 URL 주소를 입력하여 링크 버튼을 생성 및 삭제할 수 있습니다.
- **파비콘(Favicon) 추출 (Google API)**: 구글 파비콘 API(Google Favicon API)를 사용하여 링크 생성 시 입력된 목적지(Target URL)의 파비콘 이미지를 자동으로 가져와 링크 아이콘으로 표시합니다.
- **추가 예정 기능 (향후 도입)**: 각 링크의 **클릭 조회수(Click count)** 를 추적하여 보여주는 기능을 추후 가벼운 형태로 추가할 예정입니다.

### 3.4 마이링크 페이지 뷰어 (Public Page Viewer)
- **반응형 렌더링**: 모바일에 최적화되어 있으면서도, 태블릿 및 데스크톱 환경에서도 어색하지 않게 화면(Grid 등)을 제공합니다. (단, 관리자 페이지 내에서 모바일 뷰를 보여주는 별도의 미리보기(Preview) 화면은 개발하지 않습니다.)
- **빠른 로딩 속도**: 방문자가 페이지 접속 시 지연 없이 링크를 확인할 수 있도록 정적 페이지(SSG/ISR) 또는 캐싱을 적용합니다.

## 4. 데이터베이스 모델링 (Database Modeling)

데이터베이스는 계층적인 서브 컬렉션(Sub-collection) 구조를 활용하여 설계합니다.

- **Users (사용자 컬렉션)**
  - `uid`: 사용자 고유 식별자 (Document ID)
  - `displayName`: 고유 URL 슬러그 생성에 사용되는 식별자 (구글 지메일 아이디의 `@` 앞부분으로 자동 초기화됨)
  - `username`: 화면에 노출되는 실제 사용자의 이름 (인라인 편집을 통해 자유롭게 수정 가능)
  - `bio`: 자기소개 텍스트
  - **Links (서브 컬렉션)**
    - `linkId`: 개별 링크 식별자 (Document ID)
    - `title`: 링크 제목
    - `url`: 목적지 URL
    - `faviconUrl`: 자동 추출된 타겟 링크의 파비콘 이미지 주소 (Google Favicon API 결과)
    - `createdAt`: 링크 생성 일자
