# 마이링크 사용자 시나리오 (User Scenarios)

## 1. 방문자 (Visitor) 시나리오

- 사용자는 **마이링크 프로필을 확인**하기 위해 **제공받은 고유 URL(`mylink.com/닉네임`)로 접속**한다.
- 사용자는 **원하는 콘텐츠로 이동**하기 위해 **화면에 나열된 링크 버튼 중 하나를 클릭**한다.
- 사용자는 **소유자의 마이링크 프로필을 다른 사람에게 전달**하기 위해 **화면 상단의 '공유(Share)' 아이콘을 클릭하여 주소를 복사**한다.

---

## 2. 소유자 (Owner) 시나리오

### 2.1 링크 추가 (Add Link)
- 사용자는 **새로운 링크를 추가**하기 위해 **링크 리스트 하단에 위치한 '+ 링크 추가' 버튼을 클릭**한다.
- 사용자는 **연결할 목적지를 설정**하기 위해 **생성된 빈 링크 항목의 URL 입력 필드에 주소를 입력**한다.
- 사용자는 **링크의 제목을 쉽게 지정**하기 위해 **입력한 URL의 기본 웹사이트 제목(Title)이 자동으로 채워지는 것을 확인**한다.
- 사용자는 **정상적으로 링크가 반영되었는지 확인**하기 위해 **구글 파비콘 API가 아이콘을 자동으로 불러오고, 화면 하단에 '성공적으로 추가되었습니다'라는 토스트 알림이 뜨는 것을 확인**한다.

### 2.2 링크 수정 (Edit Link)
- 사용자는 **기존 링크의 제목이나 URL을 변경**하기 위해 **해당 링크 아이템에 위치한 '수정' 아이콘(또는 텍스트 영역)을 클릭**한다.
- 사용자는 **내용을 변경**하기 위해 **입력 필드에 새로운 제목이나 주소를 입력한 후 외부 영역을 클릭(또는 엔터)하여 저장**한다.
- 사용자는 **수정 결과를 확신**하기 위해 **화면 하단에 '저장되었습니다'라는 토스트 알림을 확인**한다.

### 2.3 링크 삭제 (Delete Link)
- 사용자는 **더 이상 필요 없는 링크를 화면에서 영구적으로 제거**하기 위해 **해당 링크 아이템 우측의 '삭제(휴지통)' 아이콘을 클릭**한다.
- 사용자는 **실수로 삭제하는 것을 방지**하기 위해 **화면에 나타난 "정말 삭제하시겠습니까?"라는 확인 모달 창에서 '확인'을 클릭**한다.
- 사용자는 **링크가 안전하게 지워졌음을 알기** 위해 **링크가 리스트에서 즉시 사라지는 시각적 피드백과 토스트 알림을 확인**한다.
